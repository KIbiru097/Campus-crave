## 2026-11-02 - Memoization in QR Menu Items
**Learning:** `QRMenuPage` renders all category items in a single grid (`MenuItemCard`), with parent state controlling active category, search query, cart quantity, and favorites. When `addCart` or `removeCart` was called, or when search spotlight was toggled, all rendered `MenuItemCard`s re-rendered because `MenuItemCard` was not wrapped in `React.memo`. Because `addCart`, `removeCart`, and `toggleFav` are wrapped in `useCallback` in `QRMenuPage`, wrapping `MenuItemCard` in `React.memo` cleanly avoids re-rendering unrelated cards when cart quantities or favorites change.
**Action:** When working on grid items where event callbacks are memoized by the parent, wrap card components with `React.memo` to eliminate O(N) cascades on item increment/decrement.
