## 2026-10-09 - Request-Scoped GraphQL Loader Caching for N+1 Queries & Duplicate Field Resolvers
**Learning:** In this GraphQL schema, field resolvers for `average_rating` and `review_count` ran separate PostgreSQL queries despite selecting from the same `reviews` table (`AVG(rating)` vs `COUNT(*)`). Also, `Order.cafe` re-queried identical cafes for every order in a list. Using a request-scoped `Map` attached to the GraphQL `context` to cache promises deduplicates concurrent resolver calls and combines scalar calculations into a single query without needing additional dependencies like `dataloader`.
**Action:** Always check if GraphQL field resolvers on the same type query the same table or if list field resolvers fetch identical relational entities across items, and use request context promise caching to deduplicate them.
