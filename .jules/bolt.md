## 2026-10-14 - Request-Scoped GraphQL Field Resolver Caching
**Learning:** In GraphQL schemas with nested relation field resolvers (e.g., fetching a list of orders with `cafe`, `student`, `items`, or cafes with `average_rating` and `review_count`), executing raw SQL queries in individual field resolvers causes severe N+1 database queries. Passing a request-scoped `cache: new Map()` via Apollo context and wrapping field resolvers in a memoized `getCached` helper deduplicates concurrent and repeated queries across the same request without needing external heavy caching layers.
**Action:** Always instantiate a request-scoped context cache (`Map`) for Apollo Server and wrap relational field resolvers with `getCached(context, key, fn)` to eliminate duplicate SQL queries per request.
