## 2026-09-01 - GraphQL Field Resolver Request-Scoped Deduplication
**Learning:** In GraphQL schemas with nested field resolvers (such as `Order.cafe` or `Cafe.average_rating` / `Cafe.review_count`), querying lists or multiple computed fields on the same entity produces N+1 query patterns and duplicate DB calls. Storing promises in a request-scoped `Map` (instantiated per request in Apollo context) deduplicates concurrent and sequential database operations across field resolvers during a single GraphQL execution without needing external libraries.
**Action:** Always check Apollo context for a request-scoped cache Map and wrap entity field resolvers using a helper (`getFromCacheOrFetch`) that caches pending promises to prevent duplicate queries and solve N+1 bottlenecks cleanly.
