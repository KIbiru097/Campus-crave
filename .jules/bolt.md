## 2026-11-08 - GraphQL Resolver N+1 Query Deduplication with Request-Scoped Map Cache
**Learning:** In Apollo Server resolvers, nested field resolvers like `Order.cafe` are called once per order when resolving lists of orders (`myOrders`, `availableOrders`, `cafeOrders`). Without external DataLoader dependencies or invasive architecture changes, introducing a lightweight, per-request `Map` in the Apollo `context` (`reqCache`) allows field resolvers to store and reuse the in-flight query Promise (`cache.set(key, promise)`). This deduplicates concurrent database queries across the GraphQL execution tree for the same request, collapses N identical SQL lookups down to 1 per unique entity, and guarantees zero cross-request cache leakage.
**Action:** When optimizing GraphQL field resolvers with repeated foreign key lookups across list queries, check for or instantiate a request-scoped cache in the request context and cache the query Promise before awaiting.
